## About me

I’m a software engineer specializing in C# and .NET, with a background in Computer Science and a focus on backend development. I enjoy understanding how an application works as a whole and using that perspective to guide the decisions I make in code. Whether I’m building something new or improving an existing system, I aim for solutions that meet practical needs without introducing unnecessary complexity. I see testing and maintainability as part of the development process from the beginning, so the software remains dependable and easier to evolve as requirements change.

## Tech stack

**C# & .NET** are at the core of my work. I use **ASP.NET Core** to build
backend applications, with **Entity Framework Core** and **SQL Server**
for data access and storage.

- **Testing:** xUnit · Moq · Unit & integration testing
- **Cloud & Delivery:** Azure · Docker · GitHub Actions · CI/CD
- **Security:** OAuth 2.0 · JWT · Doppler
- **Observability:** Serilog · Seq · OpenTelemetry
- **Version Control:** Git
