## About me
I'm a software engineer focused on backend development with C# and .NET. I enjoy understanding how systems work as a whole and using that perspective to make thoughtful technical decisions. Whether I'm building something new or improving existing code, I aim for practical solutions that are clear, testable, and maintainable as requirements evolve.

My work centers on the C#/.NET ecosystem, supported by tools that help me test, ship, and maintain applications throughout their lifecycle.

- **Design & Testing:** SOLID, Design Patterns, Unit & Integration Testing, xUnit, Moq
- **Cloud & Delivery:** Azure, Docker, Git, GitHub Actions, CI/CD
- **Authentication & Security:** OAuth 2.0, JWT
- **Logging & Observability:** Serilog, Seq, OpenTelemetry
